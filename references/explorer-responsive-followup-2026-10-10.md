# 组件响应式与长内容修复记录（2026-10-10）

本轮承接用户的十张截图、十一项反馈，修复 canonical 组件源码及相关 Explorer 案例。源码入口为 `assets/react-kit/src/personal-ui/`，案例从公共 barrel 复用组件。没有修改已安装 Skill 副本、版本号、发行 tag 或 Release。

## 反馈与处理

| # | 反馈 | 原因和本轮处理 |
| --- | --- | --- |
| 1 | 分裂按钮外观异常 | 后加载的通用 Button 胶囊规则覆盖主按钮连接处圆角。提高组件内部连接选择器优先级；主操作可收缩，菜单侧固定 38px，整组宽度不超过 360px 或宿主宽度，长名称省略。 |
| 2 | 焦点限制示例按钮在左 | FocusTrap 管理焦点，不负责动作布局。所有相关示例明确使用官方 `Inline justify="end"`，保持右侧操作和 Tab 循环。 |
| 3 | 筛选框总是过长 | 外层和字段层双重弹性网格把字段铺满。FilterBar 改为内容宽度与换行布局，字段默认约 320px、最大 360px，随容器收缩；保持无背景和显式查询。 |
| 4 | 缺少动态容器响应式 | FilterBar 自有 inline-size 容器在不超过 520px 时纵排字段和动作，即使桌面窗口中只有一个窄面板也会生效。Toolbar 各区域可收缩、内部换行；分页保留原有窄容器模式。 |
| 5 | 标签输入长内容无限展示 | Tag 默认最大 `min(100%,20rem)`，文字省略、删除按钮固定 28px；TagInput 内容区域最大 12rem，超出内部滚动。连续添加/删除时，仅在输入仍聚焦的情况下调整组件自身 scrollTop，保持编辑位置可见。原始值和提交值不截断。 |
| 6 | 表单提示间距 | 标签与输入之间的 7px 间距符合现有 Field 合同。右侧“必填”是既有设计，本轮保留并防止该提示自身换行，核对窄容器布局。没有把右侧提示误当成组件故障。 |
| 7 | 分页步长和页码高度不一致 | page-size Select 曾采用 44px 字段高度，页码和图标按钮为 36px。本轮将 Pagination 内 Select 高度统一为 36px，保留其独立选择能力。 |
| 8 | 标签前缀错位 | 原前缀把所有子元素强制塞入固定图标框。文字前缀改为自然宽度和行高；13px 媒体规则仅作用于 SVG/图片等媒体元素。示例补充 US/+1、图标国家、过期及可移除形式，选中不新增图标、不导致跳宽。 |
| 9 | 横幅没有圆角 | 原 Banner 无条件覆盖 Alert 圆角。本轮普通 Banner 复用 Alert 的 8px 圆角；明确启用 sticky 的贴边横幅仍使用直角。 |
| 10 | 行内消息不对齐 | 图标按整块多行文字居中。本轮 16px 图标与 20px 第一行文字对齐：单行居中、多行不随总高度漂移。 |
| 11 | 图片预览窄条/错位 | 无前后箭头的单图仍落入三列网格的第一列。本轮显式指定媒体与箭头 grid area，单图使用独立媒体列；长说明区域有界滚动且可键盘聚焦，保留多图方向键、Esc 和关闭后的焦点恢复。 |

额外修复同一 TagInput 中已确认的错误聚焦样式：错误边框与内侧焦点反馈统一为 danger 色，消除红边框与蓝光圈混用。

长 Tag 的鼠标全文查看使用原生 `title`；被实际省略的纯文字标签加入 Tab 顺序，并向辅助技术暴露完整文字。这里没有宣称键盘聚焦会显示视觉浮层。短标签不会额外增加 Tab 停靠点；删除按钮仍独立可访问。复杂 ReactNode 内容需由调用方提供可访问文案，不能把任意节点无损转换成文字。
