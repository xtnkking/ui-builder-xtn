# 名称约定

本项目唯一的正式名称为 `ui-builder-xtn`。仓库、Skill 元数据、README、官方组件预览和文档都使用这个名称，不另设组件库品牌。

业务项目属于使用者，其页面标题、Logo、文案和资源使用业务产品自己的名称。官方项目名不得作为默认标题、推广链接、生成器信息或运行时宣传写入业务页面。

组件技术命名采用中性的 `ui`，以免把仓库身份写入业务产物：

| 用途 | 当前名称 |
| --- | --- |
| 组件目录与公开入口 | `src/ui/index.ts` |
| 校验工具与安装状态 | `tools/ui/` |
| 安装、验证命令 | `scripts/install_ui.py`、`scripts/verify_ui.py`、`verify:ui` |
| 样式、内部 token、所有权标记 | `.ui-*`、`--ui-*`、`data-ui-*` |
| 本地化公共类型与 hook | `UILocale`、`UITimeZone`、`useUILocale` |

这次更名直接更新公开代码契约，不提供旧名称的兼容别名。旧项目应按当前公开入口重新接入；不要从旧版本复制实现或混用两套选择器。

不可变的历史 API 基线、已归档验收证据和冻结的旧版测试输入保留原始名称、路径与哈希。这些历史记录用于核对原始事实，不代表当前仍提供旧接口。产物扫描中的旧名称仅作为禁止泄露的检测输入。

交付业务项目时，运行其构建、来源验证及 `scripts/check_consumer_output.py --output <browser-output>`。保留必要的法律声明，并保持生产源码映射私有；中性命名不构成无法识别代码来源的保证。
