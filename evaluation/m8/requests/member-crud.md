# 成员管理工作台

请制作一个企业成员管理页面，用于查看、搜索、新增、编辑和删除成员。列表至少包含姓名、邮箱、角色、状态、加入时间和操作。筛选条件包含关键词、角色和状态；用户编辑条件时不要立即请求数据，只有点击查询或按 Enter 后才应用本次条件。

新增和编辑需要完整表单，删除需要二次确认。所有会请求数据的操作都要有明确加载状态并防止重复触发；请求失败时可以重试，同时保留最近一次成功列表，不能让整个页面突然清空或跳动。请提供可控的本地数据服务，能够演示慢响应、空结果、失败和恢复，不需要新建生产后端。

页面需要适合日常高频操作。桌面端信息密度要合理，窄屏下仍能完成查询和成员操作，不允许为了塞下内容而把文字缩得难以阅读。
