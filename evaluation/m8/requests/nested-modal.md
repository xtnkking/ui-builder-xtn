# 嵌套编辑与确认流程

请制作一个项目编辑流程：用户先从项目列表打开编辑窗口，在编辑过程中可以打开成员选择界面；成员选择界面中可以搜索并选择多名成员；保存敏感变更前还需要再次确认。取消任意一步后，用户应回到上一层继续编辑，而不是丢失已填写内容。

当多层界面同时存在时，Esc 每次只处理最上层；背景页面和被覆盖的上一层不能被误操作。成员搜索需要支持加载、空结果、失败重试和快速连续输入，旧结果不能覆盖较新的搜索。关闭整个流程后应回到原来的触发位置，页面滚动状态恢复正常。

请提供可运行的完整流程，并演示取消、确认、失败后重试以及关闭后再次打开。仅使用键盘也必须能完成主要流程，窄屏下不能出现操作按钮被遮挡或内容无法滚动的情况。
