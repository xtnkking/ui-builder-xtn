# 可搜索分页订单列表

请制作一个订单管理页面。主列表支持关键词、状态、国家和日期范围筛选，用户修改筛选条件后由查询按钮或 Enter 手动提交；列表还需要支持排序、分页、调整每页数量、勾选批量操作、列显示与隐藏，以及查看单行操作。

第一列为勾选列时，横向滚动期间勾选列和第一个数据列需要保持可见，最右侧操作列也要保持可用。加载、少量数据、空数据和错误重试时列表区域高度不能明显跳变，表头、滚动区域、底边和四个圆角需要保持完整。页面中另提供一个“最近订单”小列表，不使用分页，用来验证无分页模式。

请使用可控的本地数据服务演示慢响应、空结果、失败和恢复。桌面端要支持较宽数据表本身的必要横向滚动；在 320px 窄屏下，页面本身不能产生无意义的横向溢出，查询区和操作区仍应可用。
