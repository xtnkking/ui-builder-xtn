# 订单详情与编辑侧面板

请在订单列表中实现查看和编辑详情的右侧面板。桌面端面板应与视口顶部、右侧和底部贴合，只在左上和左下保留清晰、自然的圆角。详情内容较长时只有内容区域滚动，标题和底部操作保持可用；移动端需要转换为适合窄屏操作的布局。

查看模式可以直接关闭。编辑模式存在未保存改动时，关闭前需要确认。点击背景默认不能关闭编辑面板，但右上角关闭和 Esc 仍然可用；关闭后再次打开同一条订单，这些规则不能失效。保存操作需要加载、失败和重试状态，并防止重复提交。

请保证从列表打开、关闭和保存后的焦点位置合理，页面背景不会在面板打开时继续滚动。提供足够长的真实内容和错误情况，便于直接验证滚动、关闭和重开流程。
